# Existing model options

Checked September 8, 2026. This is **read-only research into reusing creator-offered assets**, not image generation or image-to-3D generation. No generation provider was retried. No model archives were requested or downloaded, no login was performed, and no purchase was made.

## Formats and access evidence

Sketchfab's own [Download API documentation](https://sketchfab.com/developers/download-api) lists glTF, GLB and USDZ and requires an authenticated Sketchfab account. It says original source formats such as FBX/OBJ are not available through that API. Its [download workflow documentation](https://sketchfab.com/developers/download-api/downloading-models) describes a glTF ZIP containing `scene.gltf`, geometry/animation/skin buffers and textures. Available archives vary by model; the public metadata does not disclose these candidates' exact downloadable archive formats. Do not claim a `.blend` file, editable animator control rig, or particular clip set until the downloaded archive is inspected.

The CC BY labels above are the uploaders' declared asset licenses. They do not themselves establish ownership of underlying Pokémon character rights or prove the uploaded geometry's provenance. Preserve model URL, creator, license, modification notes, and retrieval metadata if an asset is accepted; do not relabel sourced models as generated or reverse-engineered from the ROM.

## Next permitted step after the source route is selected

For a candidate selected by the user, use the normal authenticated download flow or a user-supplied archive. Inspect the actual file for skins, bones, animation channels, textures and scale. Render neutral-light close-ups and all supplied animations in Blender, then render it at the intended gameplay camera. Compare its silhouette and surfaces with the agreed target before accepting it. Source-asset reuse still needs this visual gate; a valid glTF and several clips cannot substitute for quality.

No strong trainer candidate with both suitable visual quality and clearly verified production rig was established in this bounded pass. The honest result is two creature inspection candidates plus one explicitly weak trainer fallback—not a complete approved character set.

Public metadata snapshots used for these findings are preserved in `existing-model-metadata.json` alongside this document.
